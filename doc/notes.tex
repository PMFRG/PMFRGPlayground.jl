\section{Preliminary notes}

\subsection{Notation: Multiindices}
\label{multiindex}

In various context different kinds of multiindices are used.
In the general review [\ref{PFFRGReview}], just after Eq. (16)
multiindices are introduced as $x = (i,i\omega,\mu)$,
where:

\begin{itemize}
\item $i$ is the lattice site index
\item $\omega$ is the Matsubara frequency
\item $\mu$ is the ``spin index'' (in the PFFRG case), which
  generalizes to the ``flavour index''.
\end{itemize}

In what follows, thought, we want to be rigorous,
and rigor is best communicate by being explicit,
so we will use the meaning of the multiindices
described above
to translate equations to the dumbest, most explicit form.

\subsection{Propagators}

In what follows:
\begin{itemize}
\item $a$, $b$ and latin lower-case letters represent Majorana flavours. Expressions with repeated Majorana flavour indices are implicitly summed over.
\item $x$ is the site index ($G$ can depend only on one site, because of the local $Z_2$ gauge symmetry - see \ref{PFFRGReview});
\item as a consequence, and a clarification: $G$ inverses ($G^{-1}$) are intended in flavour space;
\item Summation over site indices are always written out explicitly.
\item $T$ is the temperature, acting in the $T$-flow case as a flow parameter;
\item $\Lambda$ the cutoff scale (only in $\Lambda$-flow).
\end{itemize}

Note: In the implementation, $\Sigma$ does not have an explicit dependency on the flow parameter
(the \textsf{iSigma\_} functions just retrieve values from a data structure with
minimal manipulation).
For this reason,
in for $iG$ we use the flow parameter as a function argument,
while in the case of $\Sigma$ we merely add it as a superscript.


\subsubsection{Matrix algebra for dummies: Derivative of $M^{-1}$}
Notice that $G$ is represented as the inverse of a matrix
(in flavour space).
The derivative of the inverse of a matrix $M$ can be computed by noticing that
\begin{equation}
  \partial_\Lambda\left(M^{-1}M\right) = 0
\end{equation}
since $M^{-1}M = M M^{-1} = I$ (assuming $M$ is invertible, of course).
This means
\begin{equation}
  \partial_\Lambda \left(M^{-1}\right)  M + M^{-1}\left(\partial_\Lambda M\right) = 0 .
\end{equation}
So
\begin{equation}
  \label{derivinv}
 \frac{\partial M}{\partial \Lambda} = - M \frac{\partial \left(M^{-1}\right)}{\partial \Lambda}  M,
\end{equation}
which,
\emph{if the derivative of $M^{-1}$ commutes with $M$},
reduces to the simple case
\begin{equation}
 \frac{\partial M}{\partial \Lambda} = - M^2 \frac{\partial \left(M^{-1}\right)}{\partial \Lambda}
\end{equation}


\subsubsection{$T$ flow}
The propagator depends on $\Sigma$:
\begin{equation}
  \label{g-tflow-general}
  {(iG(\omega,T,x))}^{-1}_{ab} = \left[\left(\sqrt{T} \omega\right) \delta_{ab} +  i\Sigma^T_{ab}(x,\omega) \right]
\end{equation}

In the isotropic (Heisenberg) or diagonal (``XYZ'') case
the inverse is trivial, but not in the most general anisotropic case,
where some matrix inversion function needs to be used.

The expression \ref{g-tflow-general} comes from \ref{TemperatureFlowPaper}, Eq. 6
(with $A=0$, limiting ourselves to the case with $h=0$), by:
\begin{itemize}
\item using $\theta(T) = \frac{1}{\sqrt{T}}$
\item plug that into the general expression for $G$ that comes from the Dyson equation:
  \begin{equation}
    G^{-1} = G^{-1}_0 - \Sigma
  \end{equation}
  (That is, Eq. 6.34 in \ref{FRGBible}, or Eq.9 in \ref{TemperatureFlowPaper}).
\item obviously, multiplying by $-i$
\end{itemize}

From the $T$-$\Lambda$ flow [\ref{PMFRGXYZTLambda}] (see line 1599) we get the same expression.

The function $S$ (the ``single scale propagator'', see [\ref{PFFRGReview}], Eq. 56 and footnote 11)
is
\begin{equation}
  iS = -\left. \frac{\partial iG}{\partial T} \right|_{\Sigma^T = const} ,
\end{equation}
i.e., the derivative of this $G$ with respect to the flow parameter $T$, keeping $\Sigma$ constant.

In this case, we use $T$ as the flow parameter, so

Regarding $S$, in this case we get (using Eq. (\ref{derivinv})):
\begin{equation}
  iS_{ab} = -\frac{\omega}{2\sqrt{T}} iG_{ac} iG_{cb}
\end{equation}
Where we left understood the arguments $(\omega,T,x)$ both for functions $S_{ab}$ and $G_{ab}$.

Notice that in the Flow equations $S_{kat}$ is actually used,
which should improve the quality of the truncation (\emph{Katanin truncation}).
In this case, we use the full derivative,
where we also include the derivative $\partial_T \Sigma^T$

\begin{equation}
  iS_{kat,ab}(\omega,T,x) = -iG_{ac}(\omega,T,x) \left[\frac{\omega}{2\sqrt{T}}\delta_{cd} + i\partial_T \Sigma^T_{cd}(x,\omega) \right]iG_{db}(\omega,T,x),
\end{equation}

where for $\partial_\Lambda \Sigma^\Lambda$ we can use the derivative we compute in the flow equations.



where we have made explicit the argument dependency
since $\Sigma$ in the code will be represented as a function
without a direct dependency on $T$.

\subsubsection{$\Lambda$ flow}

From the $T$-$\Lambda$ flow code [\ref{PMFRGXYZTLambda}] (see line 1732) we get:
\begin{equation}
  {(iG(\omega,T,x,\Lambda))}^{-1}_{a,b} = \left[\left(\omega+\frac{\Lambda^2}{\omega}\right) \delta_{ab} + i \Sigma^\Lambda_{ab}(x,\omega)\right]
\end{equation}

So in this case, for $S$ we get
\begin{equation}
iS_{ab} = - \frac{2\Lambda}{\omega} iG_{ac} iG_{cb}
\end{equation}
Where we left understood the arguments $(\omega,T,x,\Lambda)$ both for functions $S_{ab}$ and $G_{ab}$, while for the ``Katanin propagator'':
\begin{equation}
  iS_{kat,ab}(\omega,T,x,\Lambda) = - \frac{\partial iG}{\partial \Lambda} = - iG_{ac} (\omega,T,x,\Lambda)\left( \frac{2\Lambda}{\omega}\delta_{cd}  +i \partial_\Lambda \Sigma_{cd}^\Lambda(x,\omega)\right)iG_{db}(\omega,T,x,\Lambda),
\end{equation}
where for $\partial_\Lambda \Sigma^\Lambda$ we can use the derivative we compute in the flow equations.

where we have made explicit the argument dependency
since $\Sigma$ in the code will be represented as a function
without direct dependencies on $T$ and $\Lambda$.

\subsection{$\Gamma$}

We define, in the T-flow case
\begin{equation}
  P^{ij}_{abcd}(\omega,\omega',T) = -iS_{kat,ab}(\omega,T,i)iG_{cd}(\omega+\omega',T,j)
\end{equation}
and in the $\Lambda$-flow case:
\begin{equation}
  P^{ij}_{abcd}(\omega,\omega',T,\Lambda) = -iS_{kat,ab}(\omega,T,i,\Lambda)iG_{cd}(\omega+\omega',T,j,\Lambda)
\end{equation}

Notice that in this case we are using the \emph{Katanin} version of $S$.

The Flow equations for $\Gamma^{ij}_{abcd}$ are different,
depending on whether the two sites $i$ and $j$ coincide
or not.


From Noah's Eqs. (3) and (4) and Siebe's notes, Eqs. (72) and (74),
we have two equations.
When the $i$ and $j$ coincide:

\begin{equation}
  \begin{aligned}
  \frac{d}{d\Lambda} \Gamma^{ii}_{abcd}(\omega_a,\omega_b,\omega_c,\omega_d) = \\
  T \sum_{\omega} \sum_k \left[ -\Gamma^{ik}_{aba'd'}(\omega_a,\omega_b,\omega,-s-\omega)
\Gamma^{ki}_{b'c'cd}(-\omega,s+\omega,\omega_c,\omega_d)P^{kk}_{a'b'c'd'}(-\omega,-s) \right. \\
+ \Gamma^{ik}_{acb'c'}(\omega_a,\omega_c,-\omega,\omega-t)\Gamma^{ki}_{a'd'bd}(\omega,t-\omega,\omega_b,\omega_d) P^{kk}_{a'b'c'd'}(-\omega,t) \\
\left. -\Gamma^{ik}_{ada'd'}(\omega_a,\omega_d,\omega,-\omega-u)\Gamma^{ki}_{b'c'bc}(-\omega,u+\omega,\omega_b,\omega_c) P^{kk}_{a'b'c'd'}(-\omega,-u) \right]
  \end{aligned}
\end{equation}

When the $i$ and $j$ differ:


\begin{equation}
  \begin{aligned}
  \frac{d}{d\Lambda} \Gamma^{ij}_{abcd}(\omega_a,\omega_b,\omega_c,\omega_d) = \\
  T \sum_\omega \left[ \sum_k -\Gamma^{ik}_{aba'd'}(\omega_a,\omega_b,\omega,-\omega-s)
    \Gamma^{kj}_{b'c'cd}(-\omega,\omega+s,\omega_c,\omega_d)
    P^{kk}_{a'b'c'd'}(-\omega,-s) \right. \\
    + \left( \Gamma^{ij}_{ab'cc'}(\omega_a,-\omega,\omega_c,\omega-t)
    \Gamma^{ij}_{ba'dd'}(\omega_b,\omega,\omega_d,-\omega+t)
    P^{ij}_{a'b'c'd'}(-\omega,t) \right. \\
   \left. + \Gamma^{ij}_{ac'cb'}(\omega_a,\omega-t,\omega_c,-\omega)
   \Gamma^{ij}_{bd'da'}(\omega_b,-\omega+t,\omega_d,\omega)P^{ji}_{a'b'c'd}(-\omega,t) \right) \\
   - \left(\Gamma^{ij}_{ad'da'}(\omega_a,-\omega-u,\omega_d,\omega)
   \Gamma^{ij}_{bc'cb'}(\omega_b,\omega+u,\omega_c,-\omega)
   P^{ij}_{a'b'c'd}(-\omega,-u) \right. \\
   + \left.\left. \Gamma^{ij}_{aa'dd'}(\omega_a,\omega,\omega_d,-\omega-u)
   \Gamma^{ij}_{bb'cc'}(\omega_b,-\omega,\omega_c,\omega+u)
   P^{ji}_{a'b'c'd'}(-\omega,-u) \right)\right] \\
  \end{aligned}
\end{equation}

\section{Angular momentum operator algebra}

As known from elementary quantum mechanics:
\begin{equation}
  \label{spinlaw}
  \left[S^\mu,S^\nu\right] = i \epsilon^{\mu\nu\rho} S^\rho .
\end{equation}

If we define
\begin{equation}
  \label{spinoperators}
  S^\mu = \frac{1}{4} c_i \ktilde^\mu_{ij}c_j
\end{equation}
What does it mean for $\ktilde$? One might hope for an easy relationship like
\begin{equation}
  \label{expectedkrelations}
  \left[\ktilde^\mu,\ktilde^\nu\right] = i \epsilon^{\mu\nu\rho} \ktilde^\rho
\end{equation}

And in his PhD thesis, Yannik claims (on Page 39) that

\begin{quote}
We can map it to a problem in linear
algebra, by using that the second quantization of the commutator between two
operators is the same as the commutator between the second quantized versions of
these two operators.
\end{quote}

Is this true? It seems a little handwavy and hopeful to me.
Expressing Eq.\ref{spinlaw} using Eq. \ref{spinoperators}
one has the following calculation, with the assumption/notation:
\begin{itemize}
%\item using $a$,$b$,$c$ and $d$ as Majorana variables meaning $c_a$, ... $c_d$
\item repeated indices are summed over ($i$ counts as $c_i$, for $i$ in $a,\ldots d$)
\item the square of a Majorana variable is $\onehalf$
\end{itemize}
\begin{equation}
\begin{aligned}
  \left[S^\mu,S^\nu\right] = c_ac_bc_cc_d \left[ \ktilde^\mu_{ab}, \ktilde^\nu_{cd} \right] = \\
c_ac_bc_cc_d \left( \ktilde^\mu_{ab} \ktilde^\nu_{cd} -  \ktilde^\nu_{ab} \ktilde^\mu_{cd}\right) = \\
(c_ac_bc_cc_d - c_cc_dc_ac_b) \ktilde^\mu_{ab} \ktilde^\nu_{cd}
\end{aligned}
\end{equation}
We can prove Eq.\ref{expectedkrelations} if we move $c_a$ and $c_b$ to the left in $c_cc_dc_ac_b$
by swapping the operators step by step,
obtaining $abcd$ and number of other terms popping up from
$\left\{c_a,c_b \right\} = \onehalf \delta_{ab}$:
\begin{equation}
  \begin{aligned}
    c_cc_d c_ac_b = - c_cc_ac_dc_b + \onehalf \delta_{ad} c_cc_b = \\
    + c_ac_cc_dc_b + \onehalf \left(- \delta_{ac} c_dc_b + \delta_{ad} c_cc_b \right)= \\
    - c_ac_cc_bc_d + \onehalf \left(+ \delta_{db} c_ac_c - \delta_{ac} c_dc_b + \delta_{ad} c_cc_b \right)= \\
    + c_ac_bc_cc_d + \onehalf \left(- \delta_{cb} c_ac_d + \delta_{db} c_ac_c - \delta_{ac} c_dc_b + \delta_{ad} c_cc_b \right)= \\
  \end{aligned}
\end{equation}
which means
\begin{equation}
     c_ac_bc_cc_d - c_cc_dc_ac_b = \onehalf \left(+ \delta_{cb} c_ac_d - \delta_{db} c_ac_c + \delta_{ac} c_dc_b - \delta_{ad} c_cc_b \right)
\end{equation}
So
\begin{equation}
  \begin{aligned}
\left[S^\mu,S^\nu\right]  = + \onehalf \ktilde^\mu_{ai} \ktilde^\nu_{id} c_ac_d \\
                           - \onehalf \ktilde^\mu_{ai}  \ktilde^\nu_{ci} c_ac_c \\
                           + \onehalf \ktilde^\mu_{ib}  \ktilde^\nu_{id} c_dc_b \\
                           - \onehalf \ktilde^\mu_{ib}  \ktilde^\nu_{ci} c_cc_b
  \end{aligned}
\end{equation}
Renaming all summed over indices in order to end up with a $ad$ binomial:
\begin{equation}
  \begin{aligned}
\left[S^\mu,S^\nu\right]  = c_ac_d \left(+ \onehalf \ktilde^\mu_{ai} \ktilde^\nu_{id} \right. \\
                          - \onehalf \ktilde^\mu_{ai}  \ktilde^\nu_{di} \\
                          + \onehalf \ktilde^\mu_{id}  \ktilde^\nu_{ia} \\
                          \left. - \onehalf \ktilde^\mu_{id}  \ktilde^\nu_{ai} \right)
  \end{aligned}
\end{equation}
Using here \textbf{the antisymmetry of $\ktilde$} and rearranging the orders of the terms,
we have
\begin{equation}
  \begin{aligned}
\left[S^\mu,S^\nu\right]  = c_ac_d \left(+ \onehalf \ktilde^\mu_{ai} \ktilde^\nu_{id} \right. \\
                          + \onehalf \ktilde^\mu_{ai}  \ktilde^\nu_{id} \\
                          - \onehalf  \ktilde^\nu_{ai} \ktilde^\mu_{id} \\
                          \left. - \onehalf \ktilde^\nu_{ai} \ktilde^\mu_{id}  \right) \\
                          = c_ac_d \left[ \ktilde^\mu_{ai}\ktilde^\nu_{id} - \ktilde^\nu_{ai}\ktilde^\mu_{id}\right]
  \end{aligned}
\end{equation}
from which Eq. \ref{expectedkrelations} trivially follows.
